1. Amaç ve Kazanımlar

Yeni alınan bir router veya switch'e herkes şifresiz girebilir. Bu uygulamada cihazlara isim, şifre ve uyarı mesajı vereceksin, şifreleri gizleyecek, ayarları kaydedecek ve başka bir bilgisayardan Telnet ve SSH ile uzaktan bağlanacaksın.

  • Konsol kablosuyla bir PC'den router'a bağlanır.
  • hostname, enable secret, konsol ve uzak erişim (VTY) şifrelerini yapılandırır.
  • service password-encryption ile şifreleri gizler, banner motd ile uyarı mesajı koyar.
  • Ayarları copy running-config startup-config ile kalıcı hale getirir.
  • Telnet ve SSH ile uzaktan bağlanır, ikisinin farkını görür.

3. Uygulama – Adım Adım

Okuma rehberi: Şekillerdeki kırmızı yuvarlaklar tıklayacağın veya yazacağın yeri, içindeki numaralar sırayı gösterir. Metindeki 1 işaretleri şekildeki numaralarla aynıdır.
1Cihazları ekle ve ağ kablolarını bağla
  1. Network Devices › Routers içinden 2911 ekle, adını R1 yap.
  2. Network Devices › Switches içinden 2960 ekle, adını SW1 yap.
  3. End Devices içinden iki PC ekle, adlarını PC1 ve PC2 yap.
  4. Connections içinden Copper Straight-Through kablosuyla şu bağlantıları yap:
Bir uçDiğer uç
R1 – GigabitEthernet0/0SW1 – GigabitEthernet0/1
SW1 – FastEthernet0/1PC1 – FastEthernet0
SW1 – FastEthernet0/2PC2 – FastEthernet0
Cihaz ekleme ve kablolama önceki uygulamadakiyle aynıdır. Router'a giden kablo ucu şimdilik kırmızı kalacak; portu Adım 5'te açacağız.
2Konsol kablosunu bağla (PC1 → R1)

Konsol kablosu, router'ı ilk kez ayarlamak için kullanılan özel kablodur. Ağ üzerinden değil, doğrudan cihaza bağlanır.

  1. 1 Sol alttan Connections (şimşek) kategorisine tıkla.
  2. 2 Listeden Console kablosunu (açık mavi kavisli çizgi) seç.
  3. 3 PC1'e tıkla → açılan listeden 4 RS 232'yi seç.
  1. 5 Şimdi R1'e tıkla → açılan listeden 6 Console portunu seç.
3PC'lere IP ver

PC › Desktop › IP Configuration › Static yolunu izle ve değerleri gir:

PCIPv4 AddressSubnet MaskDefault Gateway
PC1192.168.1.10255.255.255.0192.168.1.1
PC2192.168.1.11255.255.255.0192.168.1.1
4PC1'den Terminal ile R1'e bağlan
  1. 1 PC1'e tıkla, Desktop sekmesine geç.
  2. 2 Terminal simgesine tıkla.
  1. Ayarlar varsayılan olarak doğrudur (9600, 8, None, 1, None). Hiçbirini değiştirme.
  2. 3 OK düğmesine tıkla.
  3. Ekranda "Would you like to enter the initial configuration dialog? [yes/no]:" sorusu çıkarsa no yaz ve Enter'a bas. Sonra bir kez daha Enter'a bas; Router> istemi görünür.
5R1'i yapılandır – isim ve şifreler

Terminal penceresine aşağıdaki komutları sırayla yaz. Her satırdan sonra Enter'a bas.

Router> enable
Router# configure terminal
Router(config)# hostname R1
R1(config)# no ip domain-lookup
R1(config)# enable secret Gizli123
R1(config)# line console 0
R1(config-line)# password Konsol123
R1(config-line)# login
R1(config-line)# logging synchronous
R1(config-line)# exit
R1(config)# line vty 0 4
R1(config-line)# password Uzak123
R1(config-line)# login
R1(config-line)# exit
KomutNe işe yarar?
hostname R1Cihaza isim verir; istem R1# olur.
no ip domain-lookupYanlış yazılan komutu alan adı sanıp beklemesini engeller.
enable secretYönetici moduna (#) geçişe şifreli koruma koyar.
line console 0 + password + loginKonsol kablosuyla girişte şifre sorar. login yazılmazsa şifre sorulmaz!
logging synchronousSistem mesajlarının yazdığın komutun ortasına girmesini engeller.
line vty 0 4Aynı anda 5 uzak (Telnet/SSH) bağlantı için şifre koyar.
6R1'i yapılandır – şifre gizleme, uyarı mesajı, IP ve kaydetme
R1(config)# service password-encryption
R1(config)# banner motd #Yetkisiz giris yasaktir!#
R1(config)# interface gigabitEthernet 0/0
R1(config-if)# ip address 192.168.1.1 255.255.255.0
R1(config-if)# no shutdown
R1(config-if)# exit
R1(config)# end
R1# copy running-config startup-config
Destination filename [startup-config]?      ← sadece Enter'a bas
[OK]
KomutNe işe yarar?
service password-encryptionYapılandırmadaki düz yazılmış şifreleri gizler (okunamaz hale getirir).
banner motd #...#Cihaza bağlanan herkese gösterilecek uyarı mesajı. # işaretleri mesajın başını ve sonunu gösterir.
no shutdownKapalı olan portu açar. Kablo ucu yeşile döner.
copy running-config startup-configAyarları kalıcı belleğe kaydeder. Kaydetmezsen cihaz kapanınca tüm ayarlar silinir!
İpucu: Türkçe karakter (ş, ı, ğ, ü, ö, ç) kullanma; Cisco cihazları bu karakterleri doğru göstermez.
7SW1'i yapılandır (CLI sekmesi)

Switch'e konsol kablosu bağlamadık; bu yüzden doğrudan Packet Tracer'ın CLI sekmesini kullanacağız.

  1. 1 SW1'e tıkla ve CLI sekmesine geç. Bir kez Enter'a bas.
  2. 2 Aşağıdaki komutları yaz. Switch'te uzak erişim satırı vty 0 15'tir (16 bağlantı).
  3. 3 Switch'in IP adresi bir porta değil, VLAN 1 arayüzüne verilir.
Switch> enable
Switch# configure terminal
Switch(config)# hostname SW1
SW1(config)# no ip domain-lookup
SW1(config)# enable secret Gizli123
SW1(config)# line console 0
SW1(config-line)# password Konsol123
SW1(config-line)# login
SW1(config-line)# exit
SW1(config)# line vty 0 15
SW1(config-line)# password Uzak123
SW1(config-line)# login
SW1(config-line)# exit
SW1(config)# service password-encryption
SW1(config)# banner motd #Yetkisiz giris yasaktir!#
SW1(config)# interface vlan 1
SW1(config-if)# ip address 192.168.1.2 255.255.255.0
SW1(config-if)# no shutdown
SW1(config-if)# exit
SW1(config)# ip default-gateway 192.168.1.1
SW1(config)# end
SW1# copy running-config startup-config
8Test 1 – Konsol şifresi çalışıyor mu?
  1. 1 PC1'in Terminal penceresinde exit yaz. Oturum kapanır; Enter'a bas.
  2. 2 Uyarı mesajı (banner) görünmeli.
  3. 3 Password: sorusuna Konsol123 yaz. Yazarken ekranda hiçbir şey görünmez; bu normaldir.
  4. 4 enable yaz, şifre olarak Gizli123 gir. İstem R1# olmalı.
9Test 2 – Şifreler gizlenmiş mi?
  1. 1 R1# isteminde show running-config yaz. Liste uzunsa Space tuşuyla ilerle.
  2. 2 enable secret 5 ... satırına bak: şifre okunamaz durumda.
  3. 3 password 7 ... satırlarına bak: konsol ve VTY şifreleri de gizlenmiş.
  4. 4 Uyarı mesajı da yapılandırmada görünür.
Bilgi: Senin ekranındaki karakterler farklı olabilir. 7 türü gizleme zayıftır ve kolayca çözülebilir; enable secret (tür 5) çok daha güvenlidir. Bu yüzden enable password yerine her zaman enable secret kullanılır.
10Test 3 – PC2'den Telnet ile uzaktan bağlan
  1. 1 PC2 › Desktop › Command Prompt'u aç ve telnet 192.168.1.1 yaz.
  2. 2 Uyarı mesajı görünür. Password: sorusuna Uzak123 yaz.
  3. 3 enable yaz, Gizli123 gir. Artık PC2'den R1'i yönetebilirsin.
  4. 4 Çıkmak için exit yaz. Aynı testi switch için telnet 192.168.1.2 ile tekrarla.
Güvenlik notu: Telnet tüm bilgileri, şifreler dahil, şifrelenmeden gönderir. Ağı dinleyen biri şifreyi görebilir. Gerçek ağlarda Telnet yerine SSH kullanılır (Adım 11).
11(İsteğe bağlı) Telnet yerine SSH kullan

SSH, bağlantıyı şifreler. SSH için cihazın bir alan adına, bir şifreleme anahtarına ve bir kullanıcı hesabına ihtiyacı vardır. PC1 Terminal'inde R1'e şu komutları gir:

R1# configure terminal
R1(config)# ip domain-name okul.local
R1(config)# username admin secret Admin123
R1(config)# crypto key generate rsa
How many bits in the modulus [512]: 1024
R1(config)# ip ssh version 2
R1(config)# line vty 0 4
R1(config-line)# login local
R1(config-line)# transport input ssh
R1(config-line)# end
R1# copy running-config startup-config
KomutNe işe yarar?
ip domain-nameŞifreleme anahtarı üretmek için gereken alan adını verir.
username admin secretKullanıcı adı ve şifreli parola oluşturur.
crypto key generate rsaSSH için şifreleme anahtarı üretir. SSH sürüm 2 için en az 768, önerilen 1024 bit.
login localGirişte artık tek şifre değil, kullanıcı adı + şifre sorulur.
transport input sshSadece SSH'ye izin verir; Telnet artık çalışmaz.
  1. 1 PC2'nin Command Prompt'unda ssh -l admin 192.168.1.1 yaz (-l küçük L harfidir).
  2. 2 Password: sorusuna Admin123 yaz.
  3. 3 Şimdi telnet 192.168.1.1 dene: bağlantı reddedilmeli.
12Kaydet

File › Save As ile dosyayı AdSoyad_Guvenlik.pkt adıyla kaydet.

Bir şey çalışmıyorsa kontrol et:
  • Şifre sorulmuyorsa: line altında login komutunu yazdın mı?
  • Telnet'te "% Password required, but none set": line vty altına şifre verdin mi?
  • Telnet'te enable dediğinde "% No password set": enable secret verdin mi?
  • Telnet/ping cevap vermiyorsa: R1'de no shutdown yaptın mı, PC'lerin IP'leri doğru mu?
  • Switch'e Telnet olmuyorsa: interface vlan 1 altında IP ve no shutdown var mı?
  • Şifreler büyük/küçük harfe duyarlıdır: Gizli123 ≠ gizli123.

Not: Şekiller, Packet Tracer 8.x arayüzü esas alınarak hazırlanmış temsili çizimlerdir; sürüme göre simge yerleri ve ekran çıktıları küçük farklılıklar gösterebilir.
